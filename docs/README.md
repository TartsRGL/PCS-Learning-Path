# Project Documentation

Tato složka obsahuje sjednocenou dokumentaci projektu.

## Struktura

- `rules/` — pravidla projektu
- `context/` — projektový, obchodní, značkový a technický kontext
- `workflow/` — pracovní postupy
- `audits/` — audity a revize
- `_legacy/` — původní dokumenty před postupnou migrací

Původní dokumenty se nejdříve ukládají do `_legacy/`. Teprve poté se postupně třídí do nové struktury.
