# PCS-CSS

Welcome to my **CSS dojo**.

This part of the PCS Learning Path continues after meaningful HTML.

HTML defines meaning.
CSS defines visual response.

It’s not just about writing styles.
It’s about **deciding how structure should react across screens, states and contexts**.

## 📚 About the Project

**PCS-CSS** is a structured journey through **visual behaviour**:

* From selectors to layout systems
* From variables to responsive design
* From “how do I style this” to “why does this layout respond this way”

Each lesson builds on the last.
It’s not a style reference — it’s a trajectory.

## 🗂️ Lessons Overview

| Lesson | Focus | Highlights |
| ------ | ----- | ---------- |
| L01 | Selectors | Advanced selectors, pseudo-classes, pseudo-elements |
| L02 | Variables & Text | CSS custom properties, typography tricks |
| L03 | Element Sizing | Fixed vs fluid sizing, box models |
| L04 | Display Modes | Block, inline, flex, grid basics |
| L05 | Positioning | Static to sticky layout positions |
| L06 | Positioning Example | Navigation layout, transforms, interactive transitions |
| L07 | Responsivity | Media queries, adaptive layout variables |
| L08 | Bootstrap Intro | Integrating third-party layouts and utilities |
| L09 | Z-Index & Stacking | Stacking contexts, overlay positioning |
| L10 | Transitions & Animations | Smooth state changes, keyframe animations |
| L11 | Units & Functions | calc(), clamp(), min(), max(), absolute vs relative units |
| L12 | Typography | Web fonts, font loading, baseline alignment |
| L13 | Forms | Custom form styling, focus states, interactive controls |
| L14 | Dark Theme | Color schemes, prefers-color-scheme, system toggles |
| L15 | Grid Layout | CSS Grid templates, areas, autofill and auto-fit |
| L16 | Architecture | BEM methodology, file organization, style scalability |

## 🛠️ Method

* **Language:** CSS
* **Approach:** Structure-first, responsive, accessible
* **Rule:** CSS reacts to meaningful HTML
* **Focus:** Layout, rhythm, responsiveness and visual states

Nothing is styled just for decoration.
Every visual decision should support the structure.

## 🚀 How to Explore

1. Clone the repo:

   ```bash
   git clone https://github.com/TartsRGL/PCS-Learning-Path.git
   cd PCS-Learning-Path/PCS-CSS
   ```

2. Navigate to a lesson:

   ```bash
   cd "L01_css_selectors"
   ```

3. Open the HTML scaffold in your browser to see the CSS react.

## 🧠 Why PCS-CSS?

Because many layout problems start before CSS, but CSS is where structure becomes visible, responsive and usable.

HTML defines meaning.
CSS turns that meaning into visual behaviour.
